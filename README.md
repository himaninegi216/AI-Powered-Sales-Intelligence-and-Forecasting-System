# AI-Powered Sales Intelligence & Forecasting System

An AI-powered sales intelligence system developed as a final-year BCA project. The system combines sales analytics, customer segmentation, machine learning-based sales forecasting, sentiment analysis, and AI-powered business insights in an interactive Streamlit dashboard.

## Features

- 📊 Sales Analysis
- 📈 Monthly Sales Trend Analysis
- 🏆 Top Product Analysis
- 👥 RFM Customer Segmentation
- 🤖 K-Means Clustering
- 🔮 Machine Learning Sales Forecasting
- 💬 Customer Sentiment Analysis
- 💡 AI-Powered Business Insights
- 📱 Interactive Streamlit Dashboard

## Project Modules

### 1. Sales Analysis
Analyzes historical sales data to identify sales trends, category performance, and top-performing products.

### 2. Customer Intelligence
Uses RFM analysis and K-Means clustering to segment customers into:
- High-Value
- Loyal / Frequent
- At-Risk
- Regular / Low-Value

### 3. Sales Forecasting
Uses a Random Forest regression model with historical sales and lag-based features to forecast future sales.

### 4. Sentiment Analysis
Analyzes customer reviews and categorizes them into Positive, Negative, and Neutral sentiments.

### 5. AI Business Insights
Combines sales, customer, sentiment, and forecasting information to generate actionable business insights.

## Dashboard

The project is implemented using Streamlit and provides separate sections for:

- Overview
- Sales Analysis
- Customer Intelligence
- Forecasting
- Sentiment Analysis
- AI Insights
